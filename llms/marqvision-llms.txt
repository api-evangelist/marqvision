## API status

MarqVision operates a customer-facing API but publishes no public developer surface.

- The public status page lists **"MarqAI API"** as a monitored component alongside
  "MarqAI Dashboard" — https://status.marqvision.com/api/v2/components.json
- The provider blog describes the Marq AI Slack app as "the first product built on our
  Action-Enabled API", exposing `/enforce {URL}` and `/summary` commands —
  https://www.marqvision.com/blog/slack-integration
- There is **no** developer portal, API reference, OpenAPI/AsyncAPI/GraphQL contract, SDK,
  CLI, MCP server, or agent card. docs.marqvision.com and developer.marqvision.com do not
  resolve; api.marqvision.com returns 404 on every path probed.
- Programmatic access is arranged through a customer success manager or the demo waitlist.
